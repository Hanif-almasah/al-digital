# Al Digital

Responsive Indonesian landing page, built with standalone HTML, CSS, and JavaScript. No build process required.

## Run locally

    python3 -m http.server 8080

Open http://localhost:8080.

## Content status

Initial creative direction based only on the supplied brand name, Al Digital. Service descriptions and positioning are draft copy awaiting brand confirmation. No fabricated client logos, testimonials, results, prices, or performance metrics are used. The visual showcase is explicitly labeled as a brand exploration, not client work.

The brief form generates a local summary and offers a clipboard copy. It does not send or store submissions. An official email or WhatsApp destination must be provided before lead delivery can be enabled. This limitation is stated next to the form and in the FAQ.

## Deployment

GitHub Pages serves the main branch root. All project assets are relative paths. Optional Google Fonts load remotely with local sans-serif fallbacks. There are no analytics, tracking scripts, API keys, or backend dependencies.
